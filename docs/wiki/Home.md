# fm-infra 위키

**이 위키는 저장소의 `docs/wiki/` 를 그대로 옮겨 놓은 것이다.**

여기서 직접 고치지 않는다. 다음 동기화 때 덮어써진다.
고치려면 저장소의 `docs/wiki/` 에서 고치고 PR 을 연다.

`main` 에 반영되면 몇 초 안에 이 위키가 갱신된다.

## 왜 위키로 보내나

저장소에 있는 문서는 clone 하지 않으면 못 본다.
기획이나 디자인처럼 코드를 받지 않는 사람과 나눌 문서만 여기 둔다.

코드 리뷰 기준, 검증 절차, 스키마 근거처럼 **개발자가 코드와 함께 보는 문서는 위키로 보내지 않는다.**
그런 문서는 `docs/` 아래 원래 자리에 있다.
